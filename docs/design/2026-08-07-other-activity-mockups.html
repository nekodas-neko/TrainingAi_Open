Workout screen · the Other Activity row

It's a door to half the app — drawn as a grey slab.

The card above it shows five exercises, forty-five minutes, a muscle map and four recovery percentages. The row below it shows a grey rectangle and two words. That gap is the problem — not the styling. Behind that button sit a running plan with a run scheduled for today, a weekly zone-minute quota you're 72 minutes short on, a steps quota, a heart profile and a trends section. The row fetches none of it and says none of it.

It already knows there's a run today

/api/running-plan returns a pending prescription with a type and a duration. The workout card would call that "Recommended today". This row calls it nothing.

Three destinations, not one

Tapping it opens a menu of Run, Guided walk and Log activity. Several designs here promote those onto the screen and delete a whole tap.

Cyan is already taken

Start Workout is cyan. Any cardio treatment in the same cyan competes with it for the same "press me" — which is why C2 uses the walk modality's green instead. Noted on each mockup that hits it.

One thing I noticed that isn't what you asked about

In your screenshot the RECOVERY chip row is clipped — the first chip reads "…ms" with its label cut off at the left edge, and the last one is flush against the card border. It's a horizontally scrolled strip whose first item is scrolled partly out of view on first paint. Worth a separate look; I haven't touched it.

Where I'd go

A1 Next up is the one I'd build. It costs almost nothing — the data is already fetched on the cardio screen — and it's the only change that makes the row impossible to ignore for the right reason: it stops being a place and starts being a scheduled thing. On days with no run planned it falls back to A5's "No cardio logged today", so the row is never blank.

B1 Fifth slide is the strongest idea and the largest build. The dots under the carousel already promise a set of sessions; cardio not being one of them is the actual structural oddity on this screen. It's a bigger change than a restyle and worth treating as its own piece of work.

The honest caution on the data-bearing options (A1–A4): they put a second network dependency on a screen that currently paints instantly from the workout cache. Each would need its own cache seed, or the row flashes empty on every visit — which would be worse than the grey slab.
