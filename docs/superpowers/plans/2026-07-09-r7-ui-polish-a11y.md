(Chunk 2). Where no device is available in-session, land with an explicit `projectOverview.md`
Known-Issues row marking the inset/compositor items **NOT device-verified**.

**Goal:** fix the black-rendering workout-load chart and the double-inset day-review sheet,
extract the drifted dismissible-banner pattern into one WebView-safe primitive, and clear the

## Chunk 1 — Black-rendering charts + double-inset sheet (UI-H1, UI-M1)

Governing rules: *Visual consistency & theme* — "Never pass a `var(--x)` string to
chart.js/canvas paint APIs … canvas `fillStyle` can't resolve CSS custom properties and
silently renders black … `resolveColor` is a shared import, never re-implemented per
component." *One Formula, One Place*. *Safe-Area Insets* — "`SheetContent side="bottom"` …
own the bottom inset — never add `pb-safe*` inside a bottom sheet; `p-0` does NOT strip the
baked padding."

### 1. Hoist `resolveColor` (+ `fillColor`) to a shared module

Create `lib/chart-colors.ts` — lift the two helpers verbatim out of
`components/health/trend-sparkline.tsx:24-42` (they are pure, client-only-guarded, and already
carry the canonical explanatory comment):

```ts
// lib/chart-colors.ts
// Chart.js paints on a <canvas>, whose fillStyle/strokeStyle cannot resolve CSS custom
// properties — a `var(--x)` colour silently falls back to black. Resolve it to the concrete
// computed value before handing it to chart.js. Client-only (guards on `window`).
export function resolveColor(color: string): string {
  if (color.startsWith("var(") && typeof window !== "undefined") {
    const name = color.slice(4, -1).split(",")[0].trim();
    const resolved = getComputedStyle(document.documentElement).getPropertyValue(name).trim();
    if (resolved) return resolved;
  }
  return color;
}

// Translucent fill for an area under a line. The `+"22"` hex-alpha shortcut only works for
// #rrggbb; anything else (oklch, rgb, resolved var) needs color-mix.
export function fillColor(color: string): string {
  return /^#[0-9a-f]{6}$/i.test(color)
    ? color + "22"
    : `color-mix(in srgb, ${color} 14%, transparent)`;
}
```

## Chunk 2 — `DismissibleBanner` primitive + fix the two broken nested-control banners (UI-L4, UI-M2, UI-M3)

Governing rules: *Android WebView Gotchas* — "never put interactive content (including `span
role="button"`) inside a real `<button>` — invalid HTML with undefined WebView behaviour, and
the span escapes the global 44px tap-target floor … Dismissible banners follow the
container-div + separate dismiss-`<button>` pattern (the session-select APK banner is the
reference)." *Visual consistency* — "Any pattern at ≥2 sites gets extracted before a third
copy." *Interactive elements are real controls … The WebView nested-control exception —
`<div role="button">` — still applies where cards contain other controls.*

### 1. Create the primitive: `components/ui/dismissible-banner.tsx`

Design constraints it must encode so no future copy re-breaks:
- Outer element is a plain `<div>` (never a `<button>`) so it can legally contain other
  controls.
- The tappable body is a `<div role="button" tabIndex={0}>` (the sanctioned card-containing-
  controls exception) **or** an `<a>` when it's a link — with keyboard activation.
- The dismiss control is a **separate sibling `<button aria-label>`**, never nested in the body.
- When expandable, `aria-expanded` lives on the body role="button"; a chevron is a visual
  indicator inside it (not a nested control).
- 44px tap floor on the dismiss button (`p-2`, ≥40px, plus the global floor).

```tsx
"use client";

import { X, ChevronDownIcon, ChevronUpIcon } from "lucide-react";
import { cn } from "@/lib/utils";

interface DismissibleBannerProps {
  icon?: React.ReactNode;
  title: React.ReactNode;
  subtitle?: React.ReactNode;
  /** Body tap action (open a sheet, toggle expand). Omit for a purely informational banner. */
  onActivate?: () => void;
  /** Alternative to onActivate: body is a link. Mutually exclusive with onActivate. */
  href?: string;
  /** Show a chevron + set aria-expanded on the body. */
  expandable?: boolean;
  expanded?: boolean;
  onDismiss: () => void;
  dismissLabel?: string;
  /** Rendered under a divider when expanded. */
  children?: React.ReactNode;
  className?: string;
  style?: React.CSSProperties;
}

export function DismissibleBanner({
  icon, title, subtitle, onActivate, href, expandable, expanded,
  onDismiss, dismissLabel = "Dismiss", children, className, style,
}: DismissibleBannerProps) {
  const bodyClass = "flex flex-1 items-center gap-3 min-w-0 text-left";
  const body = (
    <>
      {icon && <span className="flex-none">{icon}</span>}
      <span className="min-w-0">
        <span className="block text-sm font-semibold leading-tight">{title}</span>
        {subtitle && <span className="block text-[10px] text-muted-foreground">{subtitle}</span>}
      </span>
    </>
  );

  return (
    <div
      className={cn("mx-4 mb-3 rounded-2xl border border-border bg-card overflow-hidden", className)}
      style={style}
    >
      <div className="flex items-center gap-2 px-4 py-3">
        {href ? (
          <a href={href} className={bodyClass}>{body}</a>
        ) : (
          <div
            role="button"
            tabIndex={0}
            aria-expanded={expandable ? expanded : undefined}
            onClick={onActivate}
            onKeyDown={e => {
              if (onActivate && (e.key === "Enter" || e.key === " ")) { e.preventDefault(); onActivate(); }
            }}
            className={cn(bodyClass, onActivate && "cursor-pointer")}
          >
            {body}
          </div>
        )}
        <div className="flex flex-none items-center gap-1">
          {expandable && (expanded
            ? <ChevronUpIcon className="h-4 w-4 text-muted-foreground" />
            : <ChevronDownIcon className="h-4 w-4 text-muted-foreground" />)}
          <button
            type="button"
            aria-label={dismissLabel}
            onClick={e => { e.stopPropagation(); onDismiss(); }}
            className="rounded-lg p-2 text-muted-foreground hover:bg-muted/60 transition"
          >
            <X className="h-4 w-4" />
          </button>
        </div>
      </div>
      {expandable && expanded && children && (
        <div className="border-t border-border px-4 pt-3 pb-4">{children}</div>
      )}
    </div>
  );
}
```
