## Gotchas worth carrying

- **RUN `npx tsc --noEmit -p tsconfig.tests.json` BEFORE EVERY PUSH — plain `npx tsc --noEmit` TYPECHECKS NOTHING UNDER `__tests__`.** `node scripts/check-test-typecheck.js` runs it with the baseline; `e2e/` **is** covered. Then `pnpm vitest run` WHOLE (this repo has tests aimed at your prose) and `pnpm check:rules`, the only thing that counts as custom-rules-pass. **Knowing the gotcha is not running the command.**
- **⛔ DO NOT COPY A SEED-THEN-FETCH `useEffect(…, [])` FROM AN EXISTING SCREEN.** 36 such sites are FROZEN by `check-fetch-once-effects.js`; copying one fails the gate. Use `useCachedValue(key, url, ttl, { today })` — it takes the today-variant flag, and re-fetches on invalidation, which the hand-rolled shape never does.
- **A leftover `next-server` holds port 3100 without serving it** and `ss -ltn` shows nothing. **⛔ `pkill -f "next dev"` KILLS YOUR OWN SHELL** (exit 144, no log). Never use it.
- **The doc-size baseline is `wc -l` + 1 exactly and the check FAILS ON SLACK** — recompute, never splice; the script is `check-doc-index-size.js`. `doc-size-baseline-history.md` is APPEND-ONLY. On the backlog a conflict is usually two *deletions* — keep neither, unless both sides EDITED different entries.
- **`total_count: 0` is NEVER slow CI** — it is a stale base or `mergeable_state: dirty`, and **while dirty a push creates NO workflow run at all**, so the PR sits looking like it is building; confirm with `list_workflow_runs` on the branch and compare `head_sha`. Attempting the merge is the reliable green check; `expectedHeadSha` wants the **full 40 chars**. **`refusing to merge unrelated histories` is the shallow-clone graft** — `git fetch origin --deepen=100`. **Rebuild `package.json` / `changelog.ts` / `projectOverview.md` from `git show origin/main:…`, never splice.** **After ANY merge run `git status --short | grep '^UU'`.** Expect to re-merge `main` two or three times per PR on a busy day.
- **`usePathname()` reads Next's route tree**, so it is useless for any bug whose symptom IS a stale tree — `window.location` is the only honest reader. **`page.goto()` to a sub-route rebuilds history**, so a spec about back must reach the screen by tapping.
- **`locator.click()` does nothing on Nutrition and times out on `/health`** (63 retries) — use `.evaluate(el => el.click())` with a `waitForFunction` guard. **`getByText` resolves to the INNERMOST match.**
- **The Morning Check-in is a MODAL and Radix `aria-hidden`s `<main>` behind it** — every role query returns nothing and it reads as "element not found". Call `suppressMorningCheckin(page)` **before** `page.goto`.
- **`seed.sql` records NOTHING for today** — a spec asserting a day's content is red here, green on CI. **Judge a colour by sampling pixels**, a layout by `getBoundingClientRect()`. **The chromium SIGSEGV (LB-119) takes unrelated specs down with `browser.newContext: … has been closed` — that spec never ran.**
