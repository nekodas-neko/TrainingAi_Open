# WHY THIS FILE EXISTS RATHER THAN A LIST INSIDE THE TEST. analyte-keys.test.ts asserts that
# ANALYTE_KEYS covers every analyte the real report prints, and its own comment says the assertion

# whenever the table moves and can only agree with itself. That is how six haematology markers once
# sat outside the table with accidentally-correct slugs. Keeping the labels in a separate data file
# preserves the anchor; putting them in the test would not.
